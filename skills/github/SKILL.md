# GitHub Skill

## Purpose

Use this skill when the user asks to work with GitHub repositories.

## Capabilities

- Inspect repository structure
- Read repository files
- Create files
- Modify files
- Create branches
- Create commits
- Create pull requests
- Review repository changes

## Rules

1. Inspect the repository before modifying it.
2. Prefer existing project patterns.
3. Do not overwrite files unnecessarily.
4. Explain important changes.
5. Keep changes minimal and focused.

## Workflow

### Step 1

Understand the repository structure.

### Step 2

Read the relevant files.

### Step 3

Determine the required change.

### Step 4

Implement the change.

### Step 5

Review the resulting changes.

### Step 6

Run appropriate tests or checks.
