# PowerShell Skill

Use this skill when working with Windows PowerShell or PowerShell 7+, including terminal commands, automation scripts, filesystem operations, processes, environment variables, networking, services, and development workflows.

## Workflow

1. Identify the PowerShell version and environment.
2. Inspect the current directory and relevant files.
3. Understand the command before executing it.
4. Prefer PowerShell-native commands and structured objects.
5. Avoid destructive operations unless explicitly required.
6. Verify the result after changes.
