# Clawbot AI

AI-powered coding agent CLI.

## Features

- Coding agent
- Plan mode
- Ask/research mode
- Filesystem operations
- Skills
- Long-term memory
- Human approval
- Telegram integration
- OpenRouter
- Gemini

## Requirements

Node 20+
Bun 1.x

## Installation

npm install -g clawbot-ai

## Configuration

OPENROUTER_API_KEY=
OPENROUTER_DEFAULT_MODEL=
GEMINI_API_KEY=
GEMINI_DEFAULT_MODEL=
SUPERMEMORY_API_KEY=
TELEGRAM_BOT_TOKEN=
TELEGRAM_OWNER_ID=

## Usage

clawbot --help
clawbot agent
clawbot ask
clawbot plan
